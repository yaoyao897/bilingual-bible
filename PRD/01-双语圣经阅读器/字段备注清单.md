# 字段备注清单 · 中英双语对照圣经阅读器

> 本页集中归档全部技术元数据：数据文件结构、字段英文 Key、localStorage 键、数据管线脚本。页面 PRD 正文不重复展开。

---

## 一、经卷元数据 `data/books-meta.json` / `window.BIBLE_BOOKS_META`

| 字段 Key | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | string | 卷缩写（如 `GEN`/`JHN`） |
| `name_zh` | string | 中文卷名（创世记） |
| `name_en` | string | 英文卷名（Genesis） |
| `testament` | string | `OT` 旧约 / `NT` 新约 |
| `group` | string | 分组（律法书/历史书/诗歌智慧书/大小先知书/福音书/使徒行传/保罗书信/普通书信/启示录） |
| `chapters` | int | 总章数 |
| `pdf` | string | christunite.com NIV1984 PDF 链接 |
| `slug` | string | 数据文件标识 `data/chapters/{slug}.{json,js}` |

## 二、章节经文 `data/chapters/{slug}.json` / `window.BIBLE_CHAPTER_DATA[slug]`

| 字段 Key | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` / `name_zh` / `name_en` / `testament` / `group` | string | 同元数据（`total_chapters`/`pdf_url` 对应 `chapters`/`pdf`） |
| `chapters` | object | `{ "章号": [节对象…] }`，章号为字符串键、从 `"1"` 起 |
| `chapters[n][].verse` | int | 节号 |
| `chapters[n][].zh` | string | 和合本简体经文 |
| `chapters[n][].en` | string | NIV 1984 英文经文 |
| `chapters[n][].py` | string | 逐字拼音，`\|` 分隔，token 数须等于 `zh` 码点数（`buildPinyinHtml` 等长校验） |

## 三、localStorage 键

| 键 | 取值 | 说明 |
| :--- | :--- | :--- |
| `bible_view_mode` | `side` / `interlinear` / `pinyin` | 排版模式 |
| `bible_theme` | `parchment` / `light` / `dark` | 主题 |
| `bible_font_scale` | float 0.8–1.6 | 普通模式字号比例 |
| `bible_font_scale_pinyin` | float 1.0–2.8 | 拼音模式字号比例 |
| `bible_click_speak_enabled` | `true` / `false` | 点读开关 |
| `bible_last_book_slug` | slug | 上次阅读卷 |
| `bible_last_chapter` | int | 上次阅读章 |
| `bible_bookmarks` | JSON array | 书签列表，头插倒序 |

### `bible_bookmarks` 条目结构

```json
{ "slug": "1-john", "chapter": 5, "name_zh": "约翰一书", "name_en": "1 John", "ts": 1730000000000 }
```

## 五、数据管线脚本（`scripts/`）

| 脚本 | 职责 | 备注 |
| :--- | :--- | :--- |
| `fetch_all_books.py` | 并发抓 christunite.com NIV + 本地 `cuv_raw.json` 对齐生成 67 个章节 JSON | 需 `zhconv`；已修复 script/style 与实体残留 |
| `fetch_and_align.py` | 早期 5 卷原型版抓取（同上修复） | 仅历史用途 |
| `add_pinyin.py` | `pypinyin` 生成逐字 `py`，变更节自动重写并联动 `.js` 再生成 | 用 `scripts/.venv/bin/python` 运行 |
| `gen_js_data.py` | `json → data/chapters/*.js`（file:// `<script>` 兜底） | `write_if_changed` 增量 |
| `clean_scraped_junk.py` | 一次性清洗抓取残留的页尾脚本/实体 | 幂等，可重跑 |

## 六、数据质量红线（历史教训）

- christunite 整卷页尾部含社交 SDK/AdSense 脚本，解析前必须剔除 `<script>/<style>` 与 `Share With Others` 之后内容；
- 实体需先解 `&amp;` 再解 `&nbsp;`（双重编码 `&amp;nbsp;`）；`&lt;`/`&gt;` 残留直接清除；
- CUV 源个别经文含 `{` `}` 残留标记，`clean_zh_text` 已剔除；
- 经节 JSON 内严禁出现 HTML 实体、JS/CSS 代码片段（`scripts/clean_scraped_junk.py` 可回归校验）。
