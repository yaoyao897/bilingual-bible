## 二、区块规格

### 1. 顶栏 `.app-header`

| 元素 | 规格 |
| :--- | :--- |
| 品牌区 | 十字图标 † + `Bilingual Scripture` 主标 + `和合本 (CUV) · NIV 1984 Edition` 副标 |
| 卷章触发钮 | 书本图标 + `{卷名} 第{n}章` + 下拉箭头；点击开右侧抽屉 |
| 点读开关 | 双 SVG 图标（喇叭× / 喇叭声波）+ `点读: 关/开`；`is-active` 金色 |
| 排版分段 | 并排（双栏图标）/ 穿插（三横线）/ 拼音（T 字图标）；`active` 高亮 |
| 字号组 | `A-` `A+`；窄屏隐藏 `.font-scaler-group` |
| 主题钮 | 太阳图标，三主题循环 |

### 2. 副栏 `.scripture-subbar`

| 元素 | 规格 |
| :--- | :--- |
| 章分页 | `‹ 上一章` `n / N` `下一章 ›`；禁用态 `opacity:.4` |
| ☆ 收藏 | 描边星 + `收藏/已收藏`；`is-bookmarked` 金底实心星；拼音模式隐藏 |
| 点读胶囊 | 圆点 + `点读: 关/开`；`is-active` 金底+光点 |
| NIV PDF | 金色徽章，外链 `currentBook.pdf`；无 PDF 时隐藏 |

### 3. 经节区 `.main-content`

- **并排模式** `.scripture-view-side`：左中文（带节号）右英文（尾部悬浮喇叭钮），顶双语表头；
- **穿插模式** `.scripture-view-interlinear`：同一行内中文上、英文下；
- **拼音模式** `.scripture-view-pinyin`：仅中文 + ruby 上标拼音，超大字号；
- **朗读高亮** `.is-reading`：当前播报节整行高亮并 `scrollIntoView` 居中；
- **行内喇叭** `.btn-verse-speak`：hover 显现，点击朗读该节英文。

### 4. 朗读坞 `.audio-dock-container`

悬浮底部居中胶囊：`波形图标 | {En} Ch.{n} / 状态行 | ⏮ ▶ ⏭ | 语速▾ | 发音人▾`。播放中 `is-playing` 波形动画 + 暂停图标；拼音模式整体 `display:none`。

### 5. 抽屉 `.books-drawer`

- **搜索框**：`input` 即时过滤；书签 Tab 下过滤书签名；
- **Tab**：旧约 / 新约 / 书签，下划线金色激活；
- **卷列表**：分组标题（律法书/历史书/诗歌智慧书/大先知书/小先知书/福音书/使徒行传/保罗书信/普通书信/启示录）+ 卷条目（中名 + 英名 + `N章`）；
- **章号网格**：`← 返回书卷目录` + 卷名 + 6 列 `.chapter-btn`，当前章金底；
- **书签列表**：`.bookmark-item` = 主条目（`卷名 第n章` + `En Ch.n`）+ ✕ 删除钮；当前章高亮；空态引导文案。

### 6. 反馈组件

- `.bible-toast` 底部居中轻提示 2.2s；`.drawer-backdrop` 半透明遮罩点击关抽屉；
- `.pinyin-zoom-dock` 右下角 `字＋/字－` 大按钮，仅拼音模式可见。

## 三、视图模式切换规格

| 模式 | 容器 class | body class | 字号比例 | 隐藏元素 |
| :--- | :--- | :--- | :--- | :--- |
| 并排 | `scripture-view-side` | — | 0.8–1.6 (0.1步进) | 拼音字号坞 |
| 穿插 | `scripture-view-interlinear` | — | 同上 | 同上 + 双语表头 |
| 拼音 | `scripture-view-pinyin` | `mode-pinyin` | 1.0–2.8 (0.2步进，默认1.4) | 英文表头/朗读坞/点读开关/点读胶囊/PDF/收藏钮/英文副标 |

模式切换记忆：`bible_view_mode`；两档字号比例独立记忆。

## 四、响应式规则（窄屏）

- 隐藏 `.font-scaler-group`；压缩副栏控件 padding/字号；`pdf-source-link` 缩小；
- Hero 与正文 padding 收敛；朗读坞元素间距收紧。

## 五、主题规格

`data-theme` 驱动 CSS 变量：`parchment`（默认羊皮纸金）/ `light`（日间白）/ `dark`（深夜）。关键变量：`--accent-gold`、`--accent-gold-soft`、`--bg-surface-elevated`、`--text-main`、`--text-muted`、`--border-subtle`、`--font-scale-ratio`。
